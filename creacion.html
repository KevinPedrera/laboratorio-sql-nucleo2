Construye una base de datos desde cero

Escribe instrucciones MySQL para crear la base, seleccionarla, definir tablas, atributos, claves primarias y foráneas. Recibirás una revisión detallada por objetivo. Esta herramienta valida el diseño y errores habituales; no sustituye a MySQL real.

Guía rápida

CREATE DATABASE nombre_bd;
USE nombre_bd;
CREATE TABLE TablaPadre (
  id_padre INT AUTO_INCREMENT PRIMARY KEY,
  nombre VARCHAR(50) NOT NULL
);
CREATE TABLE TablaHija (
  id_hija INT AUTO_INCREMENT PRIMARY KEY,
  id_padre INT NOT NULL,
  FOREIGN KEY (id_padre) REFERENCES TablaPadre(id_padre)
);

Una clave primaria identifica cada fila; una clave foránea referencia una clave de otra tabla. Separa columnas y restricciones con comas. Usa DECIMAL(10,2), no DECIMAL(10.2).
